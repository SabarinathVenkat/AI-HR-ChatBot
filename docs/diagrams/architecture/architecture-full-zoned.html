HR Chat Agent: full system architecture by layer

In plain words

Read it top to bottom. Employees, managers and HR admins use the web app, and every request passes JWT login, a rate limit and security headers in the gateway, which attaches the verified employee ID.

The LangGraph agent runs an input guardrail, a Haiku-tier router labels the intent, and plain code picks the route. The normal route is a tool loop where Claude Sonnet calls up to five tools and drafts a cited answer that the verifier checks before it streams back. Multi-step planning requests go to a read-only Deep Agents path with two sub-agents. Submitting leave is a separate endpoint that only the employee's click reaches.

Below the agent, tools call pure leave rules and parameterized repositories, and policy questions use hybrid search with confidence tiers. All data sits in one SQLite file. A per-request trace id, the audit log, the evaluation suite and a CI workflow watch the system. For readability, the planner's own model calls, the deep-path result returning to the verifier and the web app's confirm click are described here rather than drawn.
