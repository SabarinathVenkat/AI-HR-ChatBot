HR Chat Agent: system overview

In plain words

Employees, managers and HR admins use a custom web app. Every request goes through the API gateway, which checks the login token, applies rate limits and attaches the verified employee ID.

The LangGraph agent decides what each question needs. Policy questions go to retrieval, personal data and calculations go to ten scoped tools built on tested leave rules, and multi-step planning requests go to a read-only Deep Agents path with two sub-agents.

One SQLite database holds HR data, leave drafts, policy chunks, the audit log and conversation state. Claude Sonnet writes answers and Claude Haiku routes. A per-request trace id, the audit log and an evaluation suite watch the system.
