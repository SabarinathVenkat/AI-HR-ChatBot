LangGraph agent: nodes, routing and the verify loop

In plain words

A message first passes the input guardrail, which checks its length and flags prompt-injection wording. A small Haiku-tier router then labels the intent with a confidence. A plain Python function, not the model, picks the route: ask for clarification, decline, answer small talk, handle a sensitive topic with fixed tools, plan with Deep Agents, or run the tool loop used for everything else.

The tool loop lets the model call the tools its role allows, up to five calls, then forces an answer. If the planning route fails or returns nothing, the request falls back to this same tool loop. Clarify and decline replies are fixed text and go straight to finalize.

Every drafted answer goes to the verifier, which checks numbers, dates, citations and names against the tool results. A failed draft is rewritten up to twice, then replaced by a plain answer built from the tool output. Submitting a leave request is not in this graph: the model can only prepare a draft, and the employee confirms it through a separate endpoint.
