# HR Chat Agent: Requirements

## Assessment Objective
Build an HR Chat Agent using any Agentic AI framework of your choice. The objective is to demonstrate how you design, build, and integrate an agent with knowledge sources and tools to solve a real-world HR use case. Based on the assessment and evaluation, the final participants will be selected for the program.

## Use Case: HR Chat Agent
The agent should:

1. Allow authenticated employees to interact with the HR Chat Agent.
2. Answer employee questions based on the existing HR policy documents provided/shared.
3. Use appropriate tools or database integrations where required to answer dynamic questions.

Example questions the agent could handle:

- Leave balance or leave eligibility
- Leave calculation based on company policies
- Other HR-related queries that require database information or calculations

The agent should also demonstrate:

- Appropriate tool usage
- Agent reasoning/workflow
- Context handling
- Response generation

You may choose any suitable Agentic AI framework and supporting technologies based on your design.

## Deliverables
- Working HR Chat Agent
- Any additional documentation required to explain the architecture, framework choices, tools, and implementation approach
