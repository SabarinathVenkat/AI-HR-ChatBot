# The company template goes here

Put the current Ideas2IT resume template in this folder as `template.docx`. The skill uses it when it fills the resume.

It is not kept in the repository on purpose: the repository is public and the template is a company document. Any
`.docx` in this folder is ignored by git, but `skills/build_zip.py` and `skills/install.py` copy it into the packaged skill,
so the skill still has it when you use it.
