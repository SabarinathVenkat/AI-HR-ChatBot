# What to hand back

Two things.

## 1. The tailored resume (.docx)

The company template, filled. Name the file `<Candidate name> - <Role> - DRAFT.docx`. It is a draft until RMG has reviewed it and, if RMG built it, until the candidate has approved it.
Nothing about the match or the gaps goes inside this file: the client will read it.

## 2. The "JD match and gaps" note (for RMG and the candidate, never the client)

Keep it short. Use these headings, in this order, in plain text:

- **Match**: "Must-have skills shown: 7 of 10 (70 percent)". Say which level was asked (Mirror, Bridge or Summit) and which was
  reached. If the target was not reached, say so here, first, with the number.
- **Added for the match, not in the original resume** (Bridge and Summit): put this at the very top of the note, above Match. Each skill, the project and the exact
  line, the warning line from the checker, and that the candidate must approve before the client sees the resume.
- **Inferred skills** (Bridge and Summit): each skill written in because the resume shows something that implies it, with the
  evidence ("Spring, from Spring Boot, in Payments").
- **Shown in the resume**: the JD skills the resume covers.
- **Gaps: questions for the candidate**: one line per missing skill, phrased as a question, for example
  "Have you worked with Kafka? If yes, in which project?". Must-haves first, then nice-to-haves.
- **What changed**: a short list per project, for example "Payments: named REST APIs in the Order API bullet", and a few lines, for example "Reordered projects (Payments first)", "Rewrote the summary", "Wrote two key
  highlights from the Fraud Alerts project".
- **Pictures**: which header pictures RMG kept and placed, or that none were found, or that they could not be placed.
- **Candidate-confirmed skills** (only if there are any): the skill and the projects it was written into.
- **Check result**: say that `check_claims.py` passed, or what you put back and why.
- **Look at before sending**: anything you were unsure about (an unclear date, a bullet you left as written).

Do not put the note's content into the resume, and do not tell the candidate's client about the gaps.
