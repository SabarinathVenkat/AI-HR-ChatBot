# HR Policy Library (Illustrative Sample)

> **IMPORTANT:** Ideas2IT has not published its internal HR policies. Only the items marked
> **[Public]** below come from the company's own website (see `research/ideas2it-public-facts.md`).
> Every other clause is an **illustrative sample** modeled on typical Indian IT-services practice,
> written for this demo. It is **not** Ideas2IT's actual policy. Replace these files with the
> real documents and re-index to deploy for real.

Conventions used by the indexer: each file has YAML front matter (`policy_id`, `title`, `version`,
`effective_date`, `source_status`), and each `##` heading is one retrieval chunk. Section IDs such
as `POL-02 §4.2` are what the bot cites.
